# Quickstart

## 1. Get an API key

Generate an API key from the Aurora dashboard — open the profile menu and
go to **Settings → API Keys**. Copy the key when it's shown; it won't be
displayed again.

## 2. Generate a deck

```bash
curl -X POST https://labs.gamma.app/api/v1/decks \
  -H "Authorization: Bearer ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A 5-slide overview of renewable energy trends in 2026"
  }'
```

The response includes the generated deck:

```json
{
  "presentationId": "abc123",
  "title": "Renewable Energy Trends 2026",
  "editUrl": "https://labs.gamma.app/edit/abc123",
  "viewUrl": "https://labs.gamma.app/view/abc123",
  "durationMs": 31200,
  "styleId": "editorial"
}
```

The preflight agent automatically enriches your prompt — it detects brands,
picks the best style, and expands your prompt with detail. To generate
a branded deck, just mention the company:

```bash
curl -X POST https://labs.gamma.app/api/v1/decks \
  -H "Authorization: Bearer ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "pitch deck for Stripe's payment infrastructure"
  }'
```

The response includes preflight metadata showing how your prompt was enriched:

```json
{
  "presentationId": "def456",
  "title": "Stripe — The Payment Infrastructure Platform",
  "editUrl": "https://labs.gamma.app/edit/def456",
  "viewUrl": "https://labs.gamma.app/view/def456",
  "durationMs": 45800,
  "preflightMs": 12400,
  "enrichedPrompt": "A 6-slide investor pitch for Stripe...",
  "brandResolutionMs": 10200,
  "brandStyleId": "ephemeral-brand-stripe"
}
```

## 3. Open in the editor

Click the `editUrl` to open your deck in the Aurora editor, where you can:
- Edit slides visually
- Chat with the AI to refine content
- Change the style
- Export to PDF/PPTX
