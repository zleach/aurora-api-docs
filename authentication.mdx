# Authentication

All API requests require a `Bearer` token in the `Authorization` header.

```
Authorization: Bearer <token>
```

The API accepts two types of tokens:

## API Keys (recommended for integrations)

API keys are long-lived tokens scoped to a specific user. Use these for
server-to-server integrations, scripts, and automation.

```
Authorization: Bearer ak_live_a1b2c3d4e5f6_AbCdEfGhIjKlMnOpQrStUvWxYz012345
```

### Key format

Keys follow the pattern `ak_live_<keyId>_<secret>`:
- `ak_live_` — prefix identifying the token as an API key
- `<keyId>` — 12-character identifier (used for management operations)
- `<secret>` — 32-character secret (hashed before storage, never stored in plain text)

### Creating a key

<Note>
  API key management is admin-only. Create keys via the Admin Settings
  panel (profile menu → Settings → API Keys tab) or via the API with an
  admin Firebase ID token.
</Note>

```bash
curl -X POST https://labs.gamma.app/api/v1/keys \
  -H "Authorization: Bearer ADMIN_FIREBASE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Production integration"}'
```

The raw key is returned **once** — store it securely.

### Scopes

API keys are created with these scopes:

| Scope | Grants |
|-------|--------|
| `decks:create` | Generate new decks |
| `decks:read` | Read deck status and content |

### Revoking a key

```bash
curl -X DELETE https://labs.gamma.app/api/v1/keys/KEY_ID \
  -H "Authorization: Bearer ADMIN_FIREBASE_TOKEN"
```

Revocation is permanent and immediate. Any in-flight requests using the key will fail.

## Firebase ID Tokens

Firebase ID tokens are short-lived (1 hour) tokens issued by Firebase Auth.
They implicitly have all scopes and are primarily used by the Aurora web app.

```
Authorization: Bearer eyJhbGciOiJSUzI1NiIs...
```

For programmatic use, API keys are preferred — Firebase tokens require a
client SDK to mint and expire frequently.

## Error responses

| Status | Body | Cause |
|--------|------|-------|
| `401` | `{"error": "Unauthorized"}` | No `Authorization` header |
| `401` | `{"error": "Invalid token"}` | Expired/malformed Firebase token |
| `401` | `{"error": "Invalid or revoked API key"}` | Bad or revoked API key |
| `403` | `{"error": "Forbidden", "message": "..."}` | Valid key but missing required scope |
