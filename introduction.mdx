# Aurora API

**Aurora by Gamma Labs** is an experimental way to generate AI-powered
presentations from a text prompt. It comes from [Gamma](https://gamma.app) — the
AI platform millions of people use to create presentations, documents, and
websites — and **Gamma Labs**, the team's space for testing wilder, earlier-stage
ideas in the open.

The Aurora API lets you generate full presentations programmatically. Decks are
generated entirely server-side — no browser required.

<Warning>
  **Research preview.** Aurora is an experimental research preview from Gamma
  Labs, not a generally available product. Expect rough edges and frequent
  change:

  - The API surface and generation behavior may change — or be removed —
    at any time, without notice or a versioned deprecation window.
  - Decks are preserved on a best-effort basis. **Export anything you want to
    keep** and don't store your only copy here.
  - Don't send confidential, sensitive, or production-critical data.
  - Access is limited and may change as the preview evolves.
  - Output is AI-generated and may be inaccurate — review it before sharing.
</Warning>

## How it works

1. **Authenticate** with an API key (`ak_live_...`)
2. **POST** a prompt to `/v1/decks` with optional style and template
3. **Receive** the generated deck — edit/view URLs, plus export URLs if requested
4. **Open** the deck in the Aurora editor via the returned `editUrl`

The generation pipeline uses a planner + parallel writer architecture:
- The **planner** reads your prompt and produces a slide outline
- **Writers** fan out in parallel, one per slide, each generating full HTML
- All slides are persisted to Firestore and available for editing immediately

Typical generation time: **20-60 seconds** for a 5-10 slide deck.

## Quick example

```bash
curl -X POST https://labs.gamma.app/api/v1/decks \
  -H "Authorization: Bearer ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A 6-slide pitch deck for a solar energy startup",
    "styleId": "editorial"
  }'
```
