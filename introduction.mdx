# Aurora API

The Aurora API lets you generate AI-powered presentations from a text prompt. Decks are generated entirely server-side — no browser required.

## How it works

1. **Authenticate** with an API key (`ak_live_...`)
2. **POST** a prompt to `/v1/decks` with optional style and template
3. **Receive** the generated deck — edit/view URLs, plus export URLs if requested
4. **Open** the deck in the Aurora editor via the returned `editUrl`

The generation pipeline uses a planner + parallel writer architecture:
- The **planner** reads your prompt and produces a slide outline
- **Writers** fan out in parallel, one per slide, each generating full HTML
- All slides are persisted to Firestore and available for editing immediately

Typical generation time: **20-60 seconds** for a 5-10 slide deck.

## Quick example

```bash
curl -X POST https://labs.gamma.app/api/v1/decks \
  -H "Authorization: Bearer ak_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A 6-slide pitch deck for a solar energy startup",
    "styleId": "editorial"
  }'
```
